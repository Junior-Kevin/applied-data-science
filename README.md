A comprehensive portfolio of eight real-world data science projects completed as part of the WorldQuant University Applied Data Science Lab Certificate. This repository showcases practical skills in data analysis, machine learning, statistical inference, and business intelligence across diverse domains and global contexts.
🎓 About the Program

WorldQuant University's Applied Data Science Lab is a rigorous, project-based certificate program that provides hands-on experience with real-world data science challenges. The program takes students through eight sequential projects, each building upon previous skills while introducing new techniques and domains.
📋 Project Portfolio
